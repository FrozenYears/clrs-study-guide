## 排查过程中的两个环境坑

1. **URL 是 `#/章/关/段`**：ch34/35 只有 5 关，`#/ch34/s06/s06` 会渲染
   「这个关卡还没有内容」——不是 bug。抽查矩阵要按 `#/chNN/s0L/s0stage` 生成。
2. **后台 http.server 会随前台命令结束被杀**：上一轮的 dump 全是
   ERR_CONNECTION_REFUSED 页。要么 `run_in_background`，要么同条命令内完成探活。
   另外矩阵脚本只在 FAIL 时写日志，看 0 行日志别急着断定卡死。
