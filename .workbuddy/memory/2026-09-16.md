## 本轮踩到的新坑（都值得记住）

1. **子代理会死于限流（429），且文件可能已经写完**。四个 5.4 子代理里有两个报 429 退出，
   但它们的关卡文件（24.5K / 33.2K）已经完整落盘。教训：**永远以磁盘上的文件为准重新验收，
   不要相信「代理没报告 = 没干活」，也不要把代理的汇报当成验收结果**。
2. **闸门只看得见 `chapter.js` 的 `levels` 数组里登记过的关卡**。
   `dump_levels.mjs` 是逐章 import `chapter.js` 再取 `ch.levels`，所以新建的关卡文件
   若不登记，跑闸门会**静默地不检查它**（报 0 ERROR 是假的）。
   本轮给子代理的指令是「不许碰 chapter.js」，导致其中两个的自我验收是空转；
   有一个子代理自己发现了，还在 chapter.js 里加了「临时注册」注释。
   **正确做法**：告诉子代理可以临时登记自己的关卡用于验收，最后由协调者收口重写。
3. **连续种子的 PRNG 会让「均匀性」测试假失败**。用「线性同余 + 取模」洗牌时，
   低位几乎不随机（最低位周期为 2），n=4 时位置×值的频率偏离 1/4 达 **17%**；
   换成 xorshift32 仍有 9% —— 因为 xorshift32 是 GF(2) 上的**线性**映射，
   连续种子的首个输出高度相关。**种子先做一轮乘法混合**（splitmix32 的两步）后才干净。
   最终卡方：位置×值 8.2（自由度 15）、24 种排列 22.9（自由度 23）。
4. **均匀性判据要用卡方，不要拍「偏差 < x%」**。后者与样本量挂钩：N 大时抽样噪声
   本身就超过那个百分比，必然失败。卡方统计量的期望恰好等于自由度，判据「χ² < 3×自由度」
   与 N 无关。第一次写的 1%/2% 阈值就是这么假失败的。
5. **C 里手写 Lehmer 码很容易漏成非单射**。第一次写成「左边比它小的个数 + 变基数累计」，
   结果 r1=0,r2=2 与 r1=1,r2=0 撞成同一个码，统计表把两种排列混在一起，
   表现为「卡方突然很大」。正确写法：rank_i = 右边比它小的个数，码值 = Σ rank_i·(K−1−i)!。
6. **katex 渲染器的极简 DOM 垫片里 `textContent` 只有 getter**（赋值会抛异常）。
   新增节点一律用 `createTextNode` + `appendChild`，与既有实现保持一致。
7. **`tools/smoke_browser.py` 的「必须出现」片段是在剥掉 script/style 后的原始 DOM 上查的**，
   所以 `<pre>` 里的 C 代码也参与匹配（C 文件头注释里的文件名就是靠这个被查到的）。
   而 LaTeX 碎片检查走 `visible_text`（剥掉 pre/code），两套口径不同。

1. **★ 生成器的第一个参数固定是面板输入数组**：stages.js 调用 `algoFn(arr.slice(), ...args)`。我把 queue/linked-list 生成器的首参写成 size/keys，导致 ops 收到数字 → "not iterable"。**新生成器一律写成 `(arr, ...)`.**
