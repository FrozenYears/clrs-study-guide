## 1. 公开 API 清单（全站只靠这些）

**dom.js**
- `h(tag, props?, ...children) -> HTMLElement`
- `svg(tag, props?, ...children) -> SVGElement`
- `on(el, event, fn, opts?) -> () => void`
- `$(selector, root=document) -> Element|null`
- `$$(selector, root=document) -> Element[]`

**store.js**（localStorage，防抖 200ms）
- `load() / getState() / save() / flush()`

- `markStage(ch,sec,stage,done=true) / isStageDone(...) / getStageSet(...) / chapterDone(...)`

- `addWrong(item) / clearWrong(id) / getWrong()`

**router.js**（三级 hash）
- `parse(hash?) -> route`
- `buildUrl(ch, section?, stage?) -> string`

**stepper.js**（接管 generator，每 yield=一帧；缓存帧支持回退）
- `createStepper(generator, opts?) -> { play, pause, toggle, step, stepBack, reset, setSpeed, gotoFrame, onFrame, getState, destroy }`

**katex.js**（接口可替换）
- `init(opts?)` — 传入 `opts.katex` 后整体改走真 KaTeX

## 3. 明暗主题策略

- 默认 `:root`（无属性）= 明色。
- `[data-theme="dark"]` = 强制暗色；暗色下 viz 色整体提亮保证可辨。
- 未显式选择时（`'auto'`，即移除属性）由 `@media (prefers-color-scheme: dark)` 跟随系统。
- `store.applyTheme()` 依据 `settings.theme` 写 `<html data-theme>`：选 `'auto'` 则 `removeAttribute`，选 light/dark 则 `setAttribute`。优先级=localStorage 选择 > 系统偏好。

## 4. 英文原文衬线 vs 讲解无衬线 视觉惯例

- 在 `components.css` 用属性选择器实现：`[data-kind="source"]` → `var(--font-serif)`（书页感）+ `--c-source` 米色底；`[data-kind="note"]` → `var(--font-sans)` + `--c-note` 冷蓝底，左侧色条区分。
- 两者样式/底色/字体均不同，一眼可分（满足红线 R3，禁止混排）。
- 附 `.prose-pair` 网格，宽屏下原文/讲解左右对照。
- 术语卡 `.term`（`.term-en` 斜体衬线 + `.term-zh`）保证中英对照。

## 6. 后续 agent 最容易踩的坑

1. **CSS 硬编码颜色/字号/圆角**（红线 R5）：务必只引用令牌。新增组件需要的颜色若令牌没有，先找运行时加令牌，别自己写 `#hex`/`px`。
2. **viz 颜色**：只引用 7 个 `--viz-*` 变量名，自己重新定义会破坏全站一致性；每个状态仍需叠加形状/文字标签（色盲）。
3. **原文/讲解不分**（红线 R3）：原文块必须 `data-kind="source"`，讲解 `data-kind="note"`，两者不得混排在同一个块里。
4. **动画帧字段名**（4.3）：必须用 `line/array/pointers/highlight/note/counts/invariantHolds/done`；`highlight` 仅用 `compare/active/move/sortedPrefix/pivot/visited/frontier/path/violation` 这 9 个键。生成器就地改数组没关系，但要 `yield` 全量 `array` 快照。
5. **键盘劫持**：stepper 的键盘只挂在 `opts.mount` 上，自己写交互组件时也要局部挂载，别监听 `document` 抢全局按键。
6. **reduced-motion**：动画默认尊重 `prefers-reduced-motion`，自动播放会被关；显式点击播放仍可。
7. **fetch JSON 会被 CORS 拦**：`index.html` 已硬编码结构；内容 agent 也别在 `file://` 下 fetch，改用 `import` 模块或内联数据。
8. **katex 替换**：现在用的是离线极简版，只覆盖常见记号；写公式时用标准 `\Theta`/`\frac`/`\sqrt` 等写法，将来切真 KaTeX 时无需改调用。
9. **路由格式**：章节链接用 `router.buildUrl(ch, 's01', 's04')`，附录用 `buildUrl('a','s01')`；别手写 `#/ch02/...` 以免补零不一致。
10. **别碰别人文件**（红线 R8）：viz/、algorithms/、chapters/ 不属于运行时。
