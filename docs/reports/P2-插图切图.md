## 1. 版式实测结论（探针先行，非假设）

探针脚本 `tools/_probe_layout.py` 把几十个代表页渲染成 PNG（存 `data/figs/_probe/`）并导出文本块 bbox / 字号 / 粗体，
**逐页肉眼看图**后得到以下事实：

1. **单栏**，不是双栏。页面 660 × 743 pt。
   - 正文栏横向 ≈ **x ∈ [169, 565]**（宽约 396 pt）。
   - 例外：节标题**悬挂缩进**到 x ≈ 99；递归树等宽图可至 x ≈ 101。
   - 因此切图横向取 **[92, 568]** 再按墨迹自动收边，可同时覆盖窄图与最宽的图。
2. **图注恒在图形下方**，左对齐。图注**不是**图的标题式头部。
3. 字号存在**干净的三档空档**（全书 1312 页直方图实测）：

   | 用途 | 字号 | 块数 |
   |---|---:|---:|
   | 正文 | **11.9** | 13352 |
   | 节标题 | **13.1** | 237 |
   | 图注 / 图内标注 | **6.0 – 9.9** | 大量 |
   | 夹缝噪声（图内元素） | 10.6 / 11.4 / 11.6 / 14.2 | 6 / 3 / 4 / 3 |

   即：**正文与图内文字之间有一条 11.9 ↔ 9.9 的空档**。这条空档是整套定位算法的基石。
4. **图注是唯一能靠文本定位的锚点**：图形本身是矢量线条 + 光栅位图，且图内文字是乱码，无法靠文字判断图的边界，
   只能"以图注为基准反推图区"。
5. 图注块的**第一个 span 是粗体**（`flags & 16`）；而正文里的引用（`Figure 2.2 shows how …`）是常规体 ——
   据此可靠区分「图注」与「正文引用」，二者文本前缀完全相同。

## 2. 裁切策略（`tools/04_figures.py`）

```
bottom = 图注 bbox 上沿
top    = max( 正文区上沿 62pt,
              该页所有「正文级块」与「其它图注」中，位于本图注之上且 y 最大者的下沿 )
横向   = [92, 568] pt，随后按实际墨迹四边去白边
渲染   200 DPI（zoom = 200/72）
```

要点：

- **「正文级块」判定 = 首 span 字号 ∈ [11.7, 13.5]**（即正文 11.9 / 节标题 13.1）。
  这样**自动排除图内小字**（6–9.9pt），图区上界不会被图内标注截断。
- **同页多图**（如 p550 的 Figure 20.1 / 20.2 上下堆叠）靠「其它图注的下沿」自动分界。
- **去白边**：先用灰度 `Pixmap` 的 `samples` 做 **bytes 切片**（`min(row)` / `min(col[::w])` 均为 C 速度），
  求出墨迹包围盒后再彩色渲染输出，保留红黑树的红/黑、图表的青色等**彩色信息**。
- **分页截断兜底**：若图注上方完全无墨迹，则回溯上一页，取"上一页最后一个正文块之下"整段（`split_across_pages`）。
  实测**全书未触发**（0 例"图注位于页首"），该分支保留为保护网。
- **续页图**：`Figure 18.8, continued` / `Figure 21.4, continued` 是另起一版，图号相同会造成文件名冲突，
  故唯一命名为 `fig-18-8-cont.png`（索引 `fig_id = "18.8-cont"`）。
- 文件名规范：`fig-<章>-<序号>.png`；附录为 `fig-b-2.png` 形式；续页 `fig-18-8-cont.png`。

### 索引 `data/figures.json`

每条字段：`{fig_id, chapter_key, number, caption, printed_page, pdf_page, bbox, path, width, height, bytes}`。
其中 `pdf_page` 为 0 基 PDF 页索引（`printed_page = pdf_page - 21`），`bbox` 为**去白边后**的 PDF 坐标裁切框，`path` 为相对工作目录的路径。

### 人工检查产物 `data/figs/_contact-sheet.html`

按章铺成网格，每张卡显示图片、图号、印刷页/PDF 页、像素尺寸、文件大小与图注摘要；
可疑图与跨页图带彩色角标。**不引用任何网络资源**（内联 CSS + 同目录相对路径图片），双击即可离线查看。

## 4. 验收发现的问题（含修正过程）

> 本节的三个问题都是靠**肉眼看图**发现的，自动化指标当时并未报警 —— 这正是先做小范围试跑的价值。

1. **❌→✅ 图内大字号元素被误判为正文，导致图被裁短。**
   初版判据是"字号 ≥ 11 即正文"。结果：
   - Figure 2.1 的手牌插图里，**扑克牌点数（16.7 pt）**、**大省略号（14.6 pt）**被当成正文；
   - Figure 9.2 的图内省略号是 **11.4 pt**，同样落入阈值；
   三者都被从中间切断（Figure 2.1 只剩 41 pt 高、Figure 4.1 只剩底部一条）。
   **修正**：先把判据收紧为 `[11.0, 13.6]`（修好 2.1/4.1），再依据全书字号直方图（正文恰为 11.9、节标题 13.1，
   中间无其它正文级字号）收紧为 **`[11.7, 13.5]`**，Figure 9.2 随之修复。
   → 教训：这类"图内元素字号恰好接近正文"的坑，**只能靠看原图**发现，指标测不出来。

2. **⚠️ 续页图的重号。** `Figure 18.8` 与 `Figure 21.4` 各有一个 `..., continued` 版，
   若按"章-序号"命名会互相覆盖。已加 `-cont` 后缀区分。

3. **⚠️ 宽高比超限的假阳性。** 见上节，3 张宽表被标记；已在报告与 contact sheet 中说明，未误删。

4. **ℹ️ 未触发的分支。** "图注位于页首（疑似图被分页截断）"实测 **0 例**，全书没有真正的分页截断图；
   跨页回溯逻辑保留为兜底，但未经真实样本验证。
