## 二、新发现 · 未修（**最高优先级**）

### P1 — 45 关的「原书习题」不是原书原文

`drill.bookExercises[].statement` 应逐字取自原书。实测 591 道题里，**45 关的命中率低于 60%**，
其中 **26 关为 0%**（完全没有一条能与语料对上）。

铁证（ch22/s01）：

| 标签 | 关卡里显示的文本 | 原书 22.1-1 的真实文本（`data/blocks/…ch22.json`） |
|---|---|---|
| 22.1-1 | Run BELLMAN-FORD on the graph of **Figure 22.1**, using vertex z as the source… | Run the Bellman-Ford algorithm on the directed graph of **Figure 22.4**, using vertex z as the source… |
| 22.1-2 | Show how the Bellman-Ford procedure returns FALSE… | **Prove Corollary 22.3.** |
| 22.1-3 | Is the path given by the predecessor subgraph produced by the Bellman-Ford… | Given a weighted, directed graph G = (V,E) with no negative-weight cycles, let m be the maximum… |

即：编号对、语气像、内容不是。读者看到的是「原书习题 22.1-1」，实际原文不是这句。

**0% 的 26 关**：ch11/s05、ch13/s04、ch18 s01–s03、ch19 s01/s02/s04、ch20 s02/s03/s04、
ch21 s01/s02、ch22 s01/s02/s04/s05、ch23 s01/s03、ch24 s01/s03、ch25/s03、ch26/s01、
ch27 s01/s03、ch28/s01。
**部分命中（33%–57%）的 19 关**：ch02/s03、ch03 s02/s03、ch04/s07、ch06 s03/s04、ch07 s02/s03/s04、
ch10/s03、ch19/s03、ch20 s01/s05、ch22/s03、ch23/s02、ch24/s02、ch25/s02、ch31/s07、ch35/s05。

**为什么闸门没拦住**：`04_verify_level.py` 只校验 `source` / `terms` / `claims` / `prove` 里的 `en`，
**完全不看** `drill.bookExercises[].statement`。这是闸门的盲区。

**怎么查**：本轮已把审计工具落地为

```powershell
python tools/09_audit_book_exercises.py          # 汇总 + 清单（退出码 1 = 有问题）
python tools/09_audit_book_exercises.py --detail # 逐题明细
```

**怎么修**：按 `id` 从 `data/blocks/<part>__chNN.json` 的 `type == 'exercise'` 块逐字取文本
（`tools/05_new_level.py --register` 生成的骨架本来就是逐字预填的，说明这批关卡是后来被改写的）。
建议顺手把它升级成闸门的 WARN 级检查，但**要等内容修完再加**，否则闸门会长期飘红。

### P2 — `source.printed` 的口径不统一

全站 150 关里，与本项目生成器规则（`printed = [本节起始页, pdf_end − 22]`）相比：

- 一致：约 120 关
- 终点差 1 页：46 关（声明把**下一节的首个印刷页**也算进来了，即 `[起始, 下一节起始]` 的写法）
- 差 ≥ 2 页：30 关（本轮已修 10 关；余 20 关多为**声明得比本节更窄**，即只声明了本关实际用到的页）

「差 1 页」不影响引述校验，也不与页面上的任何其他数字冲突，属可接受的口径差异；
本轮只修了**客观越界**（声明了不属于本节的页）的 10 关。若要彻底统一，规则是：
`printed = [TOC.printed_page, TOC.pdf_end − 22]`，但注意 `ch05` 的 5.4 拆成 4 关（s04–s07）
时其各自声明的 5.4.1–5.4.4 子区间是**刻意的、更准确的**，不要一并统一掉。

1. `node tools/dump_levels.mjs && python tools/04_verify_level.py` —— 先拿权威快照，**看关数对不对**。
