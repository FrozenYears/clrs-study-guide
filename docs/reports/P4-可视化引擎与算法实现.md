## 2. array.js / tree.js 引擎 API 与能力

两者均满足规范 4.4：`create(container, opts) → { render(frame), resize(), destroy()}`；纯 SVG、`render` 幂等（每次清空重建，不累积 DOM）；只引用 CSS 变量名，不硬编码颜色；状态除颜色外另有斜纹 / 边框粗细 / 文字标签三通道；`ResizeObserver` 自适应宽度。

**array.js**（下标刻度尺 1 基，角落注明「C 实现从 0 开始」）
- 能力：柱状（高度∝值）+ 数值文本；`cards` 模式（扑克牌直觉演示）；高亮 `sortedPrefix`（已定前缀，计数）、指针箭头 `i/j/key/k/p/q/r`；状态 `compare/active/move/sortedPrefix/pivot/visited/frontier/path/result/violation`。

**tree.js**（任意度数递归树 / 递归式树）
- 能力：节点标签 `label`、每层代价标注 `cost`（如 `cn`/`cn/2`）、高亮路径 `path`、展开/折叠（点击或回车触发 `opts.onToggle(id)`，可键盘操作）、分层自动布局（后序求 x、按深度求 y）。

## 3. 测试结果（node `__tests__.mjs`，44 passed / 0 failed）

- 正确性：空 / 单元素 / 已排序 / 逆序 / 含重复 / Figure 2.2 / Figure 2.4 / 多组随机，插入与归并均正确。
- **插入排序最坏比较次数**：逆序 n=6 → `cmp = 15`，与书给 `n(n−1)/2` 完全一致；n=1..8 全部等于 `n(n−1)/2`。
- **归并排序比较次数**：每实例 `cmp ≤ n⌈lg n⌉ − n + 1`（书中聚合上界）；逐次合并 `cmp ∈ [min(nL,nR), nL+nR−1]`（书中「at least n/2, at most n−1」，400 组校验通过）。
- 实测关键值：Figure 2.2 插入 `cmp=9, move=14`；Figure 2.4 归并 `cmp=17, move=7`（n=8 命中上界 17）。
