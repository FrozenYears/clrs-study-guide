## 二、修掉的真错（2 处，全部实跑核过）

两处是**同一类盲区**：嵌在关卡里的 C 文件头注释，与同一份代码的断言/正文自相矛盾。既有探针只比对「关卡正文 ↔ 语料」，不比对「内嵌 C 的注释 ↔ 断言」。

### 1. ch31：头注释的 Fibonacci 下标错了

`c/number_theory.c` 与 8 个 ch31 关卡内嵌同一份代码，头注释写：

```
 *   part 2  ...；Fibonacci 最坏情形：gcd(F_20, F_19) 恰好递归 20 次；
```

而代码、断言、正文、测试表、选择题**全**用 `gcd(F_21, F_20)`：

- `c/number_theory.c:149-152`：`ll f21 = fib(21), f20 = fib(20); ... assert(g == 1 && g_euclid_calls == 20);`
- 实测：`gcd(F_21, F_20) = gcd(10946, 6765) = 1，递归 20 次 = k ✓`

**真错**：`gcd(F_20, F_19) = gcd(6765, 4181)` 只有 **19** 步，产生不了它声称的 20 次。修法：9 份头注释统一成代码实际值 `gcd(F_21, F_20)`。

### 2. ch32：头注释的后缀数组倍增轮数错了

`c/string_match.c` 与 5 个 ch32 关卡内嵌代码头注释写「倍增 **3** 轮」，而 `c/string_match.c:271` 是 `assert(rounds == 2)`，实测打印 2 轮，正文也写 2 轮。3 轮是 $\lceil\lg 6\rceil$ 的**上界**，被当成了实测值。修法：6 份头注释统一成 2 轮。
