## 一、先纠正交接文档里一个数：伪影不是 280 条，是 24 条

第 37 轮交接说「题干里的字有约 280 条是残缺的」，依据是 `tools/_probe/artifact_count.txt`。
本轮开工第一件事是复核这个数，结论是**它错了，而且错在方法上**：

`artifact_count.py` 读的是 `tools/_levels.json` → 关卡里的 `statement`，而那些
`statement` 是从**已修复**的语料回填的。也就是说，它是在「修复器的猜测结果」上找伪影 ——
两类尤其离谱：

- 「**π 抽成 Ω** 43 条」：语料里根本没有 π 被抽成 Ω 这回事。p.69 黄金比那处的原始字节是
  `U+FFFD`，`_resolve_fffd` 按「无未闭合 `[` 就当 Ω」的假定把它猜成了 Ω，于是探测脚本
  在修复后的文本里看到了 Ω。**这是修复器猜错的产物，不是 PDF 的伪影形态。**
- 「**∈ 抽成 2** 70 条」：命中的是 `n 2`，那是 `n²` 的上标写法（`100n 2 runs faster` 是
  「$100n^2$ 跑得更快」），压根不是 `∈`。
- 「**−∞ 抽成 −1** 15 条」：命中的是 `\ue003 1` = 「− 1」，全书 1285 处，是减号。
- 「**v: d 冒号代点号** 42 条」：命中的 `speed: how long` 这类是**真的冒号**（英文正文）。

新写的 `tools/_probe/r38_stmt_final.py` 换了个口径：**直接读关卡文件里的 `statement`**
（那才是渲染出去的东西），只用可复算、且写明「为什么这是伪影」的判据。实测：

| 类 | 条数 | 性质 |
|---|---|---|
| 撇号被抽成 9（`Kruskal9s` / `We9ll`） | 12 | 真伪影 |
| `⌊⌋`/`⌈⌉` 残缺（`blg nc` / `dlg ne`） | 7 | 真伪影 |
| 括号被抽成 `. /`（`cf.n/` / `max.v/`） | 5 | 真伪影 |
| `∈` / `−∞` / `π` / `v: d` | 0 | 上一版探测的假阳性 |

**真伪影共 24 道**（不到交接文档报的 280 的十分之一）。

## 二、第 6 件：改上游、重跑、伪影归零

规矩照旧：`data/pages_fixed.jsonl` 是地面真值，只能改 `tools/02_repair.py` 那条流水线，
改完重跑下游，`09_audit_book_exercises.py` 必须仍是 0 问题。三条新规则都对着**原始语料**
（`data/pages.jsonl`）的字节写，每条都实测过边界：

1. **撇号 `9` → `’`**（`bbd2211`）
   `(?<=[A-Za-z])9(?=[A-Za-z])`。实测全书 169 处「字母 + 9 + 字母」，**全部**是缩写或所有格
   （146 个 `9s`、17 个 `9ll`、6 个 `9t`）。反例天然被挡住：真数字前面不会是字母 ——
   `COVID-19` / `the 9th` / `1990s` / `h9;16i` 一律不动。

2. **裸取整残形 `blg nc` → `⌊lg n⌋`、`dne` → `⌈n⌉`**（`bbd2211`）
   数学字体在没有 `/` 操作数时把取整竖线整个丢了。两条形状：函数名操作数
   （`b/d + lg|ln|log + 操作数 + c/e`）与裸变量（`b/d + n|m|k + c/e`）。
   写宽一档会吃掉 `basic` / `dice` / `done` / `dense` / `dele-` —— 逐条验过不误伤。

3. **`cf` / `max` / `min` 从 `ABBREV_WORDS` 里摘掉**（`bbd2211`）
   这三个词在 `ABBREV_WORDS` 里挡着括号规则，所以 `cf.n/` 修不成。实测全书紧贴点号的形态：
   `cf.n/` 11 处、`max.v/` 1 处、`min.u/` 2 处，**全是数学括号对**；而它们作缩写时点号后
   必带空格（`cf. Figure 3.1`），根本走不到那道「紧贴」守卫。摘掉安全。

4. **括号规则收数字操作数**（`22cdfb5`）
   `L .0/` = `L(0)`、`T .1/` = `T(1)` 这类底例此前修不出来（规则只认字母操作数）。
   放宽到 1–2 位数字；因为只有**配对成功**的位置才改写（栈匹配），`2.5` / `Figure 2.2` /
   `Section 3.1` 一律不受影响。
