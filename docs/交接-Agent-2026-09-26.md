## 七、踩过的坑（都值得知道）

1. **冒烟全 FAIL 时先看服务**。第 43 轮第一次跑冒烟，站点服务已被别的进程关掉，
   结果 **561 条路由全部 FAIL**。看 DOM 字节数一眼分辨：正常首页约 17 KB，
   Chrome 错误页约 43 KB。**用受监督服务起站点**，别用带 timeout 的普通命令（会中途被杀）。
2. **`git mv` 没有 `--cached` 选项**（只有 `-f/-k/-n/-v`）。第一次重写历史时用了
   `git mv --cached -f`，报错被过滤器脚本末尾的 `exit 0` 吞掉，310 个提交原样通过，
   唯一症状是 `Ref 'refs/heads/master' is unchanged`——**看起来像成功**。
   正确写法是 `git update-index --force-remove` + `--add --cacheinfo`。
3. **`filter-branch` 要清 `refs/original`**，否则旧历史仍能通过那个引用访问。
4. **`localStorage.clear()` 不清内存缓存**，hash 导航也不重载模块。测试存档状态必须真 reload。
5. **本机 Git Bash 的 PATH 是坏的**（`ls`/`mkdir`/`rm`/`head`/`tail` 都用不了）。
   用 PowerShell，或用 Python 的 `os.remove`。
6. **不要双击 `index.html`**：ES Module 在 `file://` 下被 CORS 拦，页面空白。
