## 5. 关键上下文：这些坑必须知道

### 5.1 硬规则（完整版在 `.workbuddy/memory/MEMORY.md`，共 40 条）

最高频踩雷的几条，提前划重点：

- **闸门只看得见 `chapter.js` 里 `levels` 数组登记过的关卡**。新写的关卡文件不登记
  就**不会被检查**，跑出来的「0 ERROR」是假的。看闸门结论前**先核对关卡数**。
- **`c:{…}` 对象必须自己闭合**。漏一个 `}` 会把 `tests`/`mapping` 塞进 `c` 里，
  闸门只报「chapter.js 加载失败」，现场完全看不出是哪个文件。写完一关先
  `node --check <文件>` 再谈闸门。
- **单引号字符串里的英文撇号用 `’`(U+2019) 或 `′`(U+2032)**，不能写 `\'`
  （会提前结束字符串）。注意：**语料用的是 U+2019**，若引述里该用 U+2019 而你写了
  U+2032，闸门会拒。
- **纯文本字段禁 LaTeX**：`stage.title`、`prove.steps[].title`、
  `pseudocode.more[].subtitle` 走的是 `h('h3',{},'…')`，**没有** renderMixed。
  可以放 `$...$` 的是 `zh` / `body` / `note` / 表格单元格 / `mathKit[].title`。
- **图表 `expr` 是要 eval 的 JS，变量名是 `n`**（渲染器 `new Function('n',…)`）。
  写成 `x` 会 ReferenceError，而 router 吞掉异常 → **页面空白且不报错**，
  只有无头 Chrome 抓 console 才看得见。
- **语料伪影逐字照抄**：如附录 D 的 `(AB)C` 在语料里是 `.AB/C`；第 6 章语料丢了
  全部缩进（缩进在关卡里手工补）；`l = LEFT(i)` 被抽成 `l DLEFT(i)`。
- **占位符引述写法**：`en:'@@Q|页码|起始片段|结束片段@@'` + `tools/08_fill_quotes.py`，
  不要手抄。占位符里不能出现 `|`。
- **概率类自检用卡方**（`χ² < 3×自由度`），不要拍「偏差 < x%」；PRNG 种子要先做
  乘法混合。
- **要支撑结论的统计量必须先 printf 出原始数字**，再写断言。
