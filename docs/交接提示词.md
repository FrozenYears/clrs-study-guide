## 1. 项目一句话

把《算法导论》第 4 版（2022，1312 页）拆成 **可视化、可交互、代码严谨** 的前端闯关章节站；
读者定位是「有 C 语言基础、无算法基础」。**零构建、零依赖、零网络资源**。

- 关卡模型：**九段式** —— 位置感 → 直觉 → 原文 → 伪代码 → 动手看见 → 双轨实现 → 复杂度 → 正确性 → 闯关测验（+ 章末 Boss 区 = 原书 Problems）。
- 双轨代码：**伪代码 + C**（C 程序是 `c/*.c`，关卡里内嵌同一份，必须逐字节一致）。
- 页码换算：`pdf_index（0 基）= 印刷页码 + 21`；`pdf_end` 是**独占**的（TOC 相邻节 110/110 满足 `pdf_end(k) == pdf_index(k+1)`）。

## 9. 团队与限流（重要）

- 本项目用 **worker 并行**开发（一章一个 worker）。但**额度/频率限制会让 worker 成批死于 429**
  （第 29、30 两轮都发生过，一次 5–6 个同时暴死）。
- **一律以磁盘为准验收**：worker 死了文件可能已写完，也可能一个字没写。既不要把「没报告」
  当成「没干活」，也不要把 worker 的自述当成验收结果 —— 自己跑闸门。
- 派 worker 前先确认额度；注意**不能只靠语法检查**：站点改动要用无头 Chrome dump DOM 逐路由断言。
