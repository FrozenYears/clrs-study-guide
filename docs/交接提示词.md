## 1. 项目一句话

把《算法导论》第 4 版（2022，1312 页）拆成 **可视化、可交互、代码严谨** 的前端闯关章节站；
读者定位是「有 C 语言基础、无算法基础」。**零构建、零依赖、零网络资源**。

- 关卡模型：**九段式** —— 位置感 → 直觉 → 原文 → 伪代码 → 动手看见 → 双轨实现 → 复杂度 → 正确性 → 闯关测验（+ 章末 Boss 区 = 原书 Problems）。
- 双轨代码：**伪代码 + C**（C 程序是 `c/*.c`，关卡里内嵌同一份，必须逐字节一致）。
- 页码换算：`pdf_index（0 基）= 印刷页码 + 21`；`pdf_end` 是**独占**的（TOC 相邻节 110/110 满足 `pdf_end(k) == pdf_index(k+1)`）。

## 7. 关键坑（精简版；完整 40 条见 `MEMORY.md`）

1. **引述逐字**：连语料伪影一起照抄。第 4 版记法：赋值 `=`（不是 `←`），切片 `A[p : q]`（不是 `A[p .. q]`）。
   语料里的撇号是 U+2019，手写 U+2032 会被闸门拒。
2. **纯文本字段禁 LaTeX**：`stage.title`、`prove.steps[].title`、`pseudocode.more[].subtitle` 不走
   `renderMixed`，放了 `$…$` 会原样显示反斜杠。
3. **图表 `expr` 是要 eval 的 JS，变量是 `n` 不是 `x`**（`viz/growth.js` 用 `new Function('n', …)`）；
   写错会 `ReferenceError`，router 吞掉后**页面空白但不报错** —— 必须用无头 Chrome 抓 console。
4. **闸门读 `tools/_levels.json`**：改了关卡先 `node tools/dump_levels.mjs` 再跑 `04_verify_level.py`，
   并且**核对关数**（未登记的关卡不会被检查，「0 ERROR」可能是假的）。
5. **闸门要求九段齐全**：原书无伪代码的节也要保留空 `pseudocode` 段，不能整段删。
6. **`c:{…}` 必须自己闭合**（少一个 `}` 只会报「chapter.js 加载失败」）；写完一关先
   `node --check <关卡文件>`，再谈闸门。
7. **引述用占位符 + `tools/08_fill_quotes.py`**，不要手抄：`en:'@@Q|页码|起始片段|结束片段@@'`。
8. **伪代码下标 1 基，C 数组 0 基** —— 照搬伪代码下标会段错误。
9. **统计类脚本写成文件再跑**：内联 `python -c` 的正则会被 bash 吃掉反斜杠。
10. **`git add -A <路径>` 里混进 `.gitignore` 忽略的目录会让整条 add 失败**（后面挂在 `&&` 上的
    commit 根本不执行，但 `git log` 仍打印旧提交 —— 提交后必核对哈希变了）。
11. **闸门只报「chapter.js 加载失败」时**，顺着 import 链去找真正的坏文件，别盯着 chapter.js 看。

## 9. 团队与限流（重要）

- 本项目用 **worker 并行**开发（一章一个 worker）。但**额度/频率限制会让 worker 成批死于 429**
  （第 29、30 两轮都发生过，一次 5–6 个同时暴死）。
- **一律以磁盘为准验收**：worker 死了文件可能已写完，也可能一个字没写。既不要把「没报告」
  当成「没干活」，也不要把 worker 的自述当成验收结果 —— 自己跑闸门。
- 派 worker 前先确认额度；注意**不能只靠语法检查**：站点改动要用无头 Chrome dump DOM 逐路由断言。
